# Project Name

## Overview
This project reads content documents, processes them, and creates a new design page for each solution with content that matches the requirements.

## Tone of Voice
- Calm, functional B2B product copy
- Confident without being salesy, technical without being cold
- Confident, not aggressive
- Functional, not flashy
- Trustworthy, slightly conservative
- Understated, doesn't overclaim
- Professional without corporate stiffness

## Content Sections

### Hero Section [Solution header]
- overheader: name of solution
- header: 80-100 characters - the gist of the solution, 1 longer sentence
- subheader: max 250 words

### What and Why [what and why]
- two column layout [what] [why] - both columns share the same structure: overhead, header, text
- overhead: what it does or why it matters
- header: 80-120 characters
- text: max 320 characters

### How It Works [how it works]
- two column layout
- column 1
  - overhead: "how it works"
  - header: one sentence explaining how it works (outcome oriented), max 90 characters
- column 2
  - step by step (adjust the amount of steps to fit the content from the solution document)
  - step: header (max 60 characters) + text (80-200 characters)

### Use Cases [use cases]
- two column layout
- column 1: "use cases hero container"
  - overhead: "common use cases"
  - header: max 60 characters
  - text: 120-180 characters - general description of use cases
- column 2: list of individual use cases
  - use case: header (max 60 characters) + text (80-160 characters)
 
### Illustration Section [Illustration Section]
- overhead: create fitting overhead
- paragraph (upo to 370 characters)
- use this section olny if there is a content that fits it

### Closing Section
- two layout alternatives depending on the length and structure of the solution description
  - layout 01 [closing section 01]: overhead + header and 3 paragraph columns (header + text)
  - layout 02 [closing section 02]: overhead + header and 1 paragraph columns (header + text)
- overhead: max 5 words
- header: 50-80 characters
- paragraph: header (30-40 characters) + text (350-400 characters)

### Section CTA [Section CTA]
- update the overhead with name of the solution
- Update the header content with a text catchy short (max 60 characters) claim relevant to the page content
